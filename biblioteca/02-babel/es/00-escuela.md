# Espanol: escuela documental

## Estado
Esquema inicial. El registro IANA identifica es como Spanish; este archivo no contiene un curso completo ni acredita fluidez del modelo.

## Para que existe
Separar futuros documentos de pronunciacion, escritura, vocabulario, gramatica y uso segun contexto. Cada unidad necesitara fuentes, ejemplos y comprobaciones.

## Pendiente
Material revisado por nivel, ejercicios y evaluacion independiente. Registrar un idioma no equivale a haberlo aprendido.
