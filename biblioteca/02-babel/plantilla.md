# Babel: abrir una escuela de idioma

## Registro primero
Buscar el codigo y nombre en idiomas.tsv. Conservar alias obsoletos y codigo preferido cuando existan. El catalogo incluye los registros de tipo language de una instantanea IANA; no pretende resolver toda clasificacion linguistica.

## Documentos despues
Crear una carpeta por codigo solo cuando haya contenido real. Separar introduccion, sonidos y escritura, vocabulario, gramatica, situaciones, ejercicios y fuentes. Registrar cada documento breve en registro.json con resumen y relaciones.

## Estado honesto
Una entrada de catalogo puede no tener escuela. Una escuela puede tener solo un esquema. Ninguno de estos estados demuestra dominio del idioma por Boddy.
