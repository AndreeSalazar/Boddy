# Identidad visual de Boddy

Dos ilustraciones generadas con la herramienta integrada `image_gen`, mediante la habilidad imagegen de Codex. No fueron creadas por los modelos propios de Boddy. No son capturas, diagramas de ingeniería ni evidencia de capacidades.

- `boddy-cover.png`: portada. Título BODDY, línea Rust · Local · Perú, módulos y horizonte andino.
- `boddy-network.png`: interpretación conceptual de módulos, documentos y nodos, sin texto.

Se conserva el resultado PNG original, sin edición posterior. La paleta sigue el carbón y menta de la ventana actual. El nombre fue elegido al azar por el creador del proyecto y no alude a un perro. El paisaje es una referencia artística a Perú, no a un lugar de nacimiento más específico.

Dimensiones, tamaños y hashes en [provenance.json](provenance.json).

## Prompt de portada (verbatim)

```text
Use case: stylized-concept. Asset type: elegant wide README cover illustration for a real local AI research project named Boddy, from Peru, built with Rust. Create a refined panoramic editorial technology image, approximately 2.5:1 aspect ratio. Use the existing app's visual language: near-black charcoal, restrained luminous mint/teal, subtle warm highlights. An abstract geometric core assembled from distinct connected modules and fine graph lines; a quiet Andean mountain horizon conveys Peru without tourist cliches. Spacious composition and excellent legibility. The only text is the exact title "BODDY" and the small exact line "Rust · Local · Perú". No animals, no dog, no human face, no robot mascot, no corporate logos, no comparisons or performance claims. Sophisticated, understated, crisp, not a cluttered sci-fi dashboard. This is conceptual brand artwork, not a screenshot or scientific diagram.
```
